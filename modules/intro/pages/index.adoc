TigerGraph Machine Learning Workbench is a platform designed for data scientists and AI/ML practitioners to easily develop graph-based machine learning models with production-scale graph data stored in TigerGraph.

[IMPORTANT]
====
The ML Workbench is retiring, as an improved approach for GNN model training will soon be introduced.

Its Python functions for graph feature extraction and graph embedding are still available directly through the xref:pytigergraph:gds[pyTigerGraph GDS library].

The Enterprise edition is no longer being offered. The Community edition is available on an as-is basis but is no longer being maintained.
